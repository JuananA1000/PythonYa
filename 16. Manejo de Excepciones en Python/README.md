# 16. Manejo de Excepciones en Python

Las **excepciones** son errores que se disparan durante la ejecución de un programa. En Python podemos dejar que dichas excepciones detengan el programa o en caso contrario escribir un algoritmo para reaccionar a dicha situación.

Los ejemplos más comunes de excepciones que existen:

- Convertir a entero un string sin valores numéricos.
- Dividir por cero.
- Abrir un archivo de texto inexistente o bloqueado por otra aplicación.
- Conectar con un servidor de bases de datos inactivo.
- Acceder a subíndices de listas o tuplas inexistentes.
- Llamada a un método o función inexistente.
- Importar módulos inexistentes.

La captura de excepciones nos permite crear programas más robustos y tolerantea a fallos que ocurran, evitando que el programa interrumpa su ejecución.
