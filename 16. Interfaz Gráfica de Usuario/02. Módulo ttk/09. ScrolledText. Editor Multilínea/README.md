### ScrolledText. Editor Multilínea

Vimos anteriormente el que control Entry nos permite ingresar una cadena de caracteres por teclado. **ScrolledText**, en su caso, nos permite ingresar **múltiples líneas**.

ScrolledText cuenta con métodos para extraer trozos del texto del componente.

Para poder utilizar este nuevo componente importaremos el módulo **scrolledtext** del paquete tkinter 

```python
from tkinter import scrolledtext
```

Podemos crear un **alias** para no tener que escribir *scrolledtext*:

```python
from tkinter import scrolledtext as st
```
