# Bases de Datos

En este apartado aprenderemos a trabajar con **bases de datos utilizando Python**. Estudiaremos cómo conectarnos a ellas, consultar información, insertar registros, modificarlos y eliminarlos mediante consultas SQL.

Trabajaremos con tres sistemas de bases de datos:

- **MySQL:** sistema de gestión de bases de datos relacionales muy utilizado en aplicaciones web.
- **SQLite:** base de datos ligera que almacena toda la información en un archivo, sin necesidad de instalar un servidor como por ejemplo XAMPP.
- **PostgreSQL:** sistema de bases de datos relacionales avanzado, conocido por su potencia, fiabilidad y extensibilidad.

A lo largo de los ejercicios aprenderemos a instalar los componentes necesarios, establecer conexiones desde Python y realizar operaciones básicas con cada sistema.
